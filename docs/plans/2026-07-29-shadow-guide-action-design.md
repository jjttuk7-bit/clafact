# Shadow 순서 가이드 실제 연동 설계

## 목적

Shadow Mode에서 사용자가 현재 진행 단계와 다음에 눌러야 할 기존 버튼을 즉시 알 수 있게 한다. 이 기능은 운영 Claim·리뷰·판정 데이터를 변경하지 않는 연구용 안내 기능이다.

## 검토한 방식

1. 안내문만 표시한다. 구현은 작지만 사용자가 버튼을 직접 찾아야 한다.
2. 단계 상태를 자동 계산하고, 다음 단계의 기존 조작 영역을 시각적으로 강조한다. 추천 방식이며 기존 흐름을 바꾸지 않는다.
3. 페이지를 자동 스크롤한다. 탐색 시간은 줄지만 Streamlit 재실행 시 화면 이동이 갑작스러울 수 있다.

## 확정 방식

2번을 적용한다. 자동 스크롤은 이번 범위에서 제외한다.

- 가이드는 기존 `build_shadow_step_guide()`의 상태를 단일 기준으로 사용한다.
- 각 단계에 `현재 단계`·`완료`·`검토 필요`·`대기` 상태를 표현한다.
- 가이드가 지시하는 다음 단계와 실제 화면의 해당 제목/버튼 근처에 동일한 안내 문구를 표시한다.
- 후보 검색, 근거 연결, 실제 값 대조, 검토 저장이 끝나면 기존 저장 기록을 다시 읽어 완료 상태를 계산한다.
- 기존 판정·저장 스키마와 운영 데이터에는 쓰기를 추가하지 않는다.

## 성공 기준

- 실행 후 사용자는 현재 선택 문장에 대해 다음 행동을 한 문장으로 볼 수 있다.
- 후보 검색이 완료되면 후보 탐색 단계가 완료되고 근거 연결 단계가 다음 단계가 된다.
- 실제 값 대조 결과가 `match` 또는 `mismatch`이면 검토·내보내기 단계가 다음 단계가 된다.
- 가이드 상태와 화면의 강조 문구를 단위 테스트로 보호한다.
