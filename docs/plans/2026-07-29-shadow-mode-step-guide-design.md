# Shadow Mode 단계형 사용 가이드 설계

## 목표

Shadow Mode의 기존 기능은 유지하면서, 사용자가 현재 연구 실행의 상태를 한눈에 보고 **바로 다음에 해야 할 한 가지 행동**을 알 수 있게 한다.

## 채택안: 5단계 체크리스트

마법사처럼 기능을 잠그지 않고 현재 화면 상단에 진행 상태를 보여 준다. 각 단계는 완료 여부, 간단한 설명, 다음 행동을 갖는다.

1. **Shadow 실행** — 기사 본문과 발행일로 연구 실행을 생성한다.
2. **문장 선택** — 수치 주장 문장 한 개를 선택한다.
3. **KOSIS 후보 탐색** — 선택 문장에 대해 후보를 찾고 적합한 통계표를 고른다.
4. **근거 연결·실제 값 대조** — 근거 객체를 연결하고 저장된 KOSIS 스냅샷과 문장 수치를 비교한다.
5. **검토·내보내기** — 연구 메모를 남기고 JSON/CSV를 내려받는다.

흐름: Shadow 실행 → 문장 선택 → KOSIS 후보 탐색 → 근거 연결·실제 값 대조 → 검토·내보내기

## 동작 원칙

- 완료 판단은 이미 저장된 Shadow 실행, 후보 탐색 이력, KOSIS 매핑, 실제 값 대조 기록, 검토 이력만 읽는다.
- 안내는 운영 Claim·리뷰·판정을 변경하지 않는다.
- 다음 단계가 아직 가능하지 않으면 “먼저 무엇을 해야 하는지”를 설명한다.
- 모든 단계는 다시 선택·실행할 수 있다. 체크리스트는 순서 안내이지 접근 제어가 아니다.

## 화면 구성

`Shadow Mode` 제목 아래에 `연구 진행 가이드` expander를 배치한다.

- 상단: `N / 5 단계 완료` 진행 표시
- 각 행: 번호, 단계명, `완료/다음/선택` 상태, 짧은 안내
- 마지막 미완료 필수 단계: 강조하여 다음 행동으로 표시

## 오류와 빈 상태

- 아직 Shadow 실행이 없으면 1단계만 `다음`으로 표시한다.
- KOSIS API 미설정 또는 후보가 부족해도 3단계는 완료로 간주하지 않고 수동 근거 입력 경로를 안내한다.
- 실제 값 대조가 `비교 불가`인 경우도 대조를 수행했다는 사실은 남기되 4단계는 `검토 필요`로 표시한다.
