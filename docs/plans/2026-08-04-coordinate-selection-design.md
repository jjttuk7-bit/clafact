# KOSIS 표 내부 좌표 선택 설계

> 상태: 승인됨 (2026-08-04)

## 목표

사람이 승인한 KOSIS 통계표의 원본 API 행에서 Atomic Claim과 비교할 정확한 셀 좌표를 선택하고, 선택 조건을 근거 객체에 연결한다.

## 처리 방식

1. 기존 `KOSIS 조회·스냅샷 준비`가 받은 원본 행에서 분류축을 추출한다.
   - `C1_OBJ_NM~C8_OBJ_NM` / `C1_NM~C8_NM`: 표의 분류 차원
   - `ITM_NM`: 항목
   - `PRD_DE`: 수록시점
   - `UNIT_NM`: 단위
2. Atomic Claim의 품목·시점·단위·비교방식을 기준으로 일치하는 값을 추천한다.
3. 사용자는 각 축의 추천값을 확인·수정한다.
4. 선택 조건으로 필터링된 원본 행이 정확히 1개일 때만 좌표를 확정한다.
5. 확정 좌표는 `선택 항목 (키=값)`에 채우고, 이후 기존 KOSIS 근거 저장·스냅샷·근거 연결 흐름을 그대로 사용한다.

## 안전장치

- 0개 행: 선택 조건이 원본 행과 맞지 않아 저장하지 않는다.
- 2개 이상 행: 누락된 분류축이 있다는 뜻이므로 추가 선택을 요구한다.
- 자동 추천은 값을 대신 확정하지 않는다.
- 조회한 원본 행의 값만 선택지로 사용한다.

## 범위

- 이번 단계는 좌표 추천·확인·근거 객체 연결까지다.
- KOSIS 원본값 스냅샷 저장과 일치·불일치 판정 자동화는 다음 3단계에서 완성한다.
