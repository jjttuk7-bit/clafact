# Shadow KOSIS 자동 후보 탐색 설계

## 목표

Shadow 문장을 입력으로 받아 KOSIS 통합검색 결과 중 상위 3개 통계표 후보와 설명 가능한 점수를 제시한다. 자동으로 근거를 확정하거나 운영 판정을 바꾸지 않는다.

## 흐름

1. 기존 `KosisSearchIndex`가 지표어 기반으로 KOSIS 통합검색을 수행한다.
2. 기존 재순위 결과를 후보 객체로 변환한다.
3. 문장의 시간 표현·단위·비교 기준을 표 제목과 함께 규칙 기반으로 평가한다.
4. 각 후보에 총점·일치 사유·감점 사유를 붙여 상위 3개만 보여 준다.
5. 사용자는 후보 URL을 열거나, 실제 표를 근거 객체로 저장한 뒤 기존 매핑 화면에서 승인·제외한다.

## 경계

- 통계 정의와 실제 수치 값은 자동 확정하지 않는다.
- 후보 탐색 결과는 연구용 추천이며 Claim·리뷰·판정 이력은 변경하지 않는다.
- API 키가 없거나 검색 실패 시 사유를 보여 주고 수동 근거 입력은 계속 제공한다.

## 첫 실험 규칙

- 지표어 일치: 50점
- 월·분기·연 표현과 제목의 주기 일치: 20점
- `%`와 등락률·증감률 표현 일치: 20점
- 전년동월비·전월비와 제목 표현 일치: 10점

점수는 정답 판정이 아니라 후보 우선순위다. 모든 점수·사유는 화면과 연구 기록에 남긴다.
