# 범용 수치 주장 프로필 및 문맥 보완 설계

## 목적

Shadow Mode에서 수치 문장을 KOSIS 후보 탐색 전에 구조화한다. 현재의 소비자물가 전용 규칙을 일반화해 인구·고용·물가 문장이 동일한 형식으로 처리되도록 한다.

## 결정

`ClaimProfile`은 주제, 핵심 지표, 시간 주기, 비교 기준, 단위, 수치, 문맥 보완 여부를 담는다. 문장에 지표가 없고 `이같은`, `그`, `해당` 같은 지시 표현이 있으면 앞선 수치 문장의 프로필에서 주제·지표만 이어받는다. 수치와 시간은 현재 문장의 값을 우선한다.

후보 검색은 프로필의 `search_query`를 사용한다. 검색 점수는 지표·시간·단위·비교 기준을 각각 독립 신호로 계산하고 100점 적합도로 표시한다. 어떤 신호도 없는 표는 `후보 부족`으로 보여, 0점 표가 근거 후보처럼 보이지 않게 한다.

## 초기 범위

- 주제: 소비자물가, 고용, 인구
- 문맥: 바로 앞의 수치 문장 한 개
- 비교 기준: 전년동월비, 전월비, 전년 대비
- 시간: 월, 분기, 연
- 단위: %, %p, 명/건

자동 판정과 운영 Claim·리뷰·판정 이력은 변경하지 않는다. 모든 결과는 Shadow 연구 기록이다.

## 검증

단위 테스트로 주제 추출, 문맥 상속, 동적 검색어, 후보 부족 판정을 확인한다. 기존 KOSIS 후보·근거·매핑·내보내기 테스트와 Streamlit AppTest를 함께 실행한다.
