# 후보 조건 충족도 표시 설계

> 상태: 승인됨 (2026-08-04)

## 목표

KOSIS 후보의 점수가 정답 확률이나 사실 판정처럼 오해되지 않도록, 점수의 의미와 실제 탐색 입력값을 후보 결과 화면에 함께 표시한다.

## 결정

- 기존 후보 점수식은 변경하지 않는다.
- `적합도 N점` 표기를 `후보 조건 충족도 N/100`으로 바꾼다.
- 후보 목록 위에 해당 탐색에 사용한 Claim 조건(지표·시점·단위·비교방식·지역·모집단·품목)을 표시한다.
- 각 후보의 원점수·가점·감점 아래에 “정답 확률이나 최종 판정이 아니며, 표 내부 좌표와 원본값 대조가 남아 있다”는 안내를 표시한다.
- 후보 탐색 이력 JSON에도 Atomic Claim의 `claim_subject`를 남겨 같은 부모 문장 내 품목별 탐색을 감사할 수 있게 한다.

## 선택하지 않은 방식

1. 점수식을 변경하거나 임계값을 강제하지 않는다. 골든셋으로 Top-3 재현율·Top-1 정확도를 측정하기 전에는 숫자의 의미만 투명하게 하는 것이 안전하다.
2. 점수를 삭제하지 않는다. 현재 점수는 후보 간 우선순위 비교에는 유용하며, 원점수와 근거를 함께 보여주면 재현 가능하다.

## 화면 흐름

```text
확정 Claim Card
  ↓
후보 탐색에 사용한 Claim 조건 표시
  ↓
후보 조건 충족도 75/100
원점수 90/120 · 가점 · 감점
  ↓
“확률·최종 판정 아님” 안내
  ↓
사람이 후보를 선택 → 좌표·원본값 대조 단계
```

## 완료 기준

1. 후보 선택 목록과 상세 제목 모두 `후보 조건 충족도`를 사용한다.
2. 화면에서 이 탐색에 실제 사용한 Claim 조건을 확인할 수 있다.
3. 원점수·가점·감점과 점수의 한계를 함께 볼 수 있다.
4. 후보 계산 로직과 기존 결과 순서는 바뀌지 않는다.
