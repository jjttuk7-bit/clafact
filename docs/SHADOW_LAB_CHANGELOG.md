## CHG-SHADOW-003 — 연구 전용 실행·저장 기반 추가

- 일시: 2026-07-28
- 변경: `ShadowStore`가 `data/research/shadow_lab.db`에 실험 실행, 행, 검토 이력을 분리 보관한다. `run_shadow_experiment`는 기존 Python·LLM·Hybrid 비교를 Shadow 행과 위험 신호로 변환한다.
- 영향: 운영 검증 결과와 운영 저장소에는 쓰지 않는다. LLM 오류·후보 불일치·필수 슬롯 누락은 검토 대상으로 표시된다.
- 검증: `pytest tests/test_shadow_store.py -v`, `pytest tests/test_shadow_runner.py -v`
- 다음 단계: 실행·저장·정책을 하나의 서비스 경계로 묶고 UI가 호출할 안정된 인터페이스를 만든다.

## CHG-SHADOW-006 — 검증 실험실 Shadow Mode UI 연결

- 일시: 2026-07-28

## CHG-SHADOW-012 — KOSIS 메타데이터 반자동 채우기

- 일시: 2026-07-28
- 변경: 원본 KOSIS URL의 `orgId`·`tblId`를 검증한 뒤, KOSIS API 응답의 표 제목·작성 기관·지표·분류 차원·선택 항목·주기·단위를 근거 객체 입력 초안으로 자동 채운다.
- 안전 기준: API 응답에 없는 통계 정의·대상 범위·잠정/확정 여부는 추정하지 않고 비워 둔다. `KOSIS_API_KEY` 또는 URL의 `orgId`가 없으면 호출하지 않고 화면에 원인을 안내한다.
- 영향: 사용자 입력 초안만 갱신하며, 근거 객체를 저장하거나 운영 Claim·리뷰·판정 이력을 바꾸지 않는다.
- 검증: 자동 변환 테스트 2건을 포함한 KOSIS 근거·Shadow 매핑 테스트 9건, Python 문법 검사, Streamlit AppTest의 자동 채우기 버튼 렌더링을 통과했다.
- 다음 단계: 원본 표의 정의·조사 기준 문구를 별도 추출 후보로 제안하고, 사람이 승인한 값만 근거 객체에 반영한다.
## CHG-SHADOW-013 — 통계표 구조 유형 자동 분류

- 일시: 2026-07-28
- 변경: KOSIS API 행의 시간·지역·분류 차원·지표 항목 변화 패턴을 분석해 `시계열형`, `지역 비교형`, `교차표형`, `지표 묶음형`, `판정 보류`로 분류한다. 유형뿐 아니라 판정 이유와 관찰된 차원을 함께 반환한다.
- 영향: 자동 채우기 시 구조 유형을 근거 객체 초안에 제안하고, 사용자가 화면에서 수정할 수 있다. 근거 객체에는 최종 선택 유형만 저장하며 운영 Claim·리뷰·판정에는 영향을 주지 않는다.
- 검증: 구조 유형 규칙 4건, 근거 객체 저장·자동 채우기·Shadow 매핑을 포함한 테스트 14건, Python 문법 검사, Streamlit AppTest의 구조 유형 선택기 렌더링을 통과했다.
- 다음 단계: 뉴스 문장과 통계표의 시간·단위·지역·차원 조건 일치도를 평가해 연결 후보의 신뢰도를 점수화한다.
## CHG-SHADOW-014 — 뉴스 문장·KOSIS 근거 적용 가능성 평가

- 일시: 2026-07-28
- 변경: Shadow 문장과 선택한 KOSIS 근거 객체를 지표명, 단위, 시간 주기, 명시적 선택 조건으로 비교해 0~100점의 `근거 적용 가능성`과 사유를 만든다. 결과는 표가 문장의 근거로 적합한지에 대한 신호이며, 수치 사실 판정이 아니다.
- 안전 기준: 단위가 충돌하면 부분 점수가 높아도 `검토 필요`로 표시한다. 문장이나 표에 없는 조건은 일치라고 추정하지 않고 `직접 일치 미확인`으로 기록한다.
- 영향: 문장-표 연결 시 점수·사유를 화면에 표시하고, `kosis_shadow_mapping.db`의 연구 이력에 보존한다. 운영 Claim·리뷰·판정 이력은 변경하지 않는다.
- 검증: 일치·단위 충돌 테스트 2건, 연결 이력 보존 테스트, 구조 분류·근거 객체·자동 채우기·Shadow 매핑을 포함한 테스트 17건, Python 문법 검사를 통과했다.
- 다음 단계: 실제 KOSIS 표의 선택 시점·값·개정 이력까지 연결해, 적용 가능성 평가를 근거 재현성 평가로 확장한다.
## CHG-SHADOW-015 — KOSIS 조회 재현 스냅샷·개정 이력 보존

- 일시: 2026-07-28
- 변경: 자동 KOSIS 조회 후 근거 객체를 저장하면 기관 ID·통계표 ID·조회 파라미터·키 안전 재현 URL·조회 시점·기간별 값·단위·지표·선택 조건·최종수정일(`LST_CHN_DE`)·응답 내용 해시를 연구 전용 스냅샷으로 보존한다. 근거 객체는 `snapshot_id`로 해당 스냅샷을 참조한다.
- 영향: 자동 조회를 거친 저장에만 `data/research/kosis_evidence_snapshot.db`가 추가된다. 수동 입력은 기존 근거 객체 저장만 수행한다. 운영 Claim·리뷰·판정 이력은 변경하지 않는다.
- 검증: 스냅샷 값·개정일·해시·연결 ID·저장소 테스트를 포함한 KOSIS 근거·구조 분류·적용 가능성·Shadow 매핑 테스트 20건, Python 문법 검사, Streamlit AppTest의 입력·자동 조회·저장 제어 렌더링을 통과했다.
- 다음 단계: 저장된 스냅샷을 화면에서 조회·다운로드하고, 같은 표의 신규 조회 결과와 비교해 개정 감지 이력을 만든다.
## CHG-SHADOW-016 — KOSIS 스냅샷 조회·다운로드·개정 감지
